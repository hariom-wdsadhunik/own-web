# Portfolio Analytics Strategy (Privacy-First)

**Project:** Hari Om — Personal Portfolio Website  
**Date:** August 31, 2026  

---

## 1. Privacy Principles
- Zero third-party tracking cookies or personal data harvesting.
- Fully compliant with GDPR, CCPA, and privacy-first web standards.
- Analytics are strictly used to measure content utility and project interest.

---

## 2. Proposed Analytics Event Matrix

| Event Name | Trigger | Purpose |
| :--- | :--- | :--- |
| `project_case_study_opened` | User clicks "View Case Study" | Measure project interest |
| `lab_experiment_opened` | User clicks "View Experiment" | Measure research prototype engagement |
| `email_inquiry_clicked` | User clicks "Send Email Inquiry" | Track conversion intent |
| `github_link_clicked` | User clicks external GitHub link | Track source code inspection |
